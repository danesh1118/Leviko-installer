# ⚡ LEVIKO Panel Installer

### نصب‌کننده خودکار LEVIKO Panel روی Cloudflare Workers

با یک API Token، Worker + D1 + Binding را خودکار می‌سازد.

## استفاده آنلاین

بعد از آپلود روی GitHub Pages:

**https://danesh1118.github.io/leviko-installer/**

یا همین `index.html` را در مرورگر باز کنید.

## مراحل

1. دکمه **Create API Token** را بزنید
2. توکن را کپی و در نصب‌کننده پیست کنید
3. نام Worker و دیتابیس را تنظیم کنید
4. **Deploy** بزنید
5. لینک پنل آماده است
